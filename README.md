# 역사 송 퀴즈 ♫

초등학교 5·6학년을 위한 역사 인물 퀴즈 가사 만들기 웹사이트입니다.

## 사용 방법

1. 유명한 한국 역사 인물 20명 중 한 명을 선택합니다.
2. 나라와 시대를 확인하고 업적 세 가지를 입력합니다. ‘예시 채우기’로 시작할 수 있습니다.
3. 느낌·장르·목소리를 선택하고 가사를 만듭니다.
4. 가사를 복사하거나 TXT로 저장합니다. ‘친구에게 퀴즈 내기’는 인물 선택 화면을 가리고 정답을 숨깁니다.
5. Suno Custom 모드에서 ‘가사만 복사’한 내용을 Lyrics에, ‘음악 지침만 복사’한 내용을 Styles / Style of Music에 각각 붙여 넣습니다. Instrumental은 끕니다. [공식 가사 사용 안내](https://help.suno.com/en/articles/2415873)
6. ‘다른 가사로 다시 만들기’를 누르면 다른 이야기 방식으로 바뀝니다. TXT 저장 파일에는 가사와 음악 지침이 나뉘어 함께 들어갑니다.

## 생성 방식과 범위

- 입력한 업적과 장르별 문장, 느낌별 표현, 8개 이야기 방식(시간 열차·역사 탐정·별빛 편지·비밀 미션·전시관·퀴즈 무대·퍼즐·숨바꼭질), 4가지 구성을 조합하는 **브라우저 내 규칙 기반 가사 생성기**입니다. 방문할 때 무작위 위치에서 시작하고 연속 생성 시 이야기 방식이 바뀝니다. 업적 순서·연결 문장·후렴·구성도 달라집니다. 가능한 조합은 유한하며 생성형 AI API에 연결하지 않습니다. 실제 음원이나 목소리도 생성하지 않습니다.
- 별도로 보이는 음악 지침에는 느낌, 장르, 목소리, BPM, 악기, 편곡, 한국어 발음 및 정답 숨김 안내가 들어갑니다. 가사와 지침은 독립적으로 복사됩니다.
- 인물 이름과 주요 별명·호를 출력에서 가립니다. 이름 사이의 공백, 일부 보이지 않는 문자도 처리합니다. 모든 역사적 별칭이나 사용자가 직접 적은 외국어 표기까지 탐지하지는 않으므로 출제 전 가사를 확인하세요.
- 업적 예시는 학습을 돕기 위한 짧은 요약입니다. 입력 내용을 자동으로 사실 검증하지 않습니다. 사실 확인 자료: [국사편찬위원회 우리역사넷](https://contents.history.go.kr/).
- 학생 이름, 로그인, API 키 없이 동작합니다. 입력은 브라우저 메모리에만 있고 새로고침하면 사라집니다. 분석·광고 추적 도구를 사용하지 않습니다.
- 가사와 음악 지침을 복사만 하며, 외부 서비스로 자동 전송하지 않습니다. Suno가 지침을 따르는 정도와 실제 음악은 Suno에서 결정됩니다.

## 실행 및 검증

Node.js 20 이상에서 별도 설치 없이 실행합니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
```

정적 호스팅에 필요한 파일은 `index.html`, `style.css`, `app.mjs`, `generator.mjs`, `.nojekyll`입니다. GitHub Pages에서 브랜치 `main`, 폴더 `/ (root)`를 선택하면 배포할 수 있습니다.

테스트는 전체 20명과 모든 스타일 조합, 업적 유지, 이름·별명 숨김, 잘못된 입력, 다른 가사 생성을 검증합니다.
